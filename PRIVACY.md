# Política de privacidad

Esta aplicación es de uso personal y la utiliza únicamente su propietario para subir y gestionar vídeos en su propio canal de YouTube (Yuzu Sensei).

- **Datos que se acceden:** solo los de la cuenta de YouTube del propietario, mediante la API de YouTube, para subir vídeos y gestionar listas de reproducción.
- **Datos de terceros:** la aplicación no recopila, almacena, vende ni comparte datos de otros usuarios.
- **Almacenamiento:** las credenciales de acceso se guardan de forma privada en el servidor del propietario y no se comparten.
- **Revocar el acceso:** puede hacerse en cualquier momento desde https://myaccount.google.com/permissions
